# 既知事項・未確認事項（known_unknowns.md）

分類: VERIFIED（確認済）／ INFERRED（推定）／ APPROXIMATED（実装近似）／ UNVERIFIED（未確認）。
未確認を確定仕様として扱わない。各未確認には検証方法を記す。

## A. 確認済み（VERIFIED）— 回路図 R1 由来

- 信号経路全体（入力→2ch プリ→共用ドライバ→FX→位相反転→6V6 PP→OT→SP）
- 真空管構成と役割（V1/V2/V4=12AX7A、V3/V5=12AT7、V6/V7=6V6GT）
- Vintage トーンスタック定数（Treble 250k, Bass 250k, slope 100k, 250pF/0.1/0.047）
- Burn の 3 ゲイン段構成と結合値、TMB トーンの主要定数
- Fat 回路（R13 10M / C7 47pF、リレー K3）
- 位相反転 LTP、NFB R132 820Ω、固定バイアス（R156 調整）
- ソリッドステート整流、B+ タップ、±15V レギュレータ
- スプリング・タンク `4AB3C1B`、OT P/N 0041318000

## B2. Phase 3 実装状況（Vintage）

- Vintage トーンスタック: 回路図の実定数が Fender 伝達関数（R7 Yeh/R8 Faust）に完全一致 → **VERIFIED** として bilinear 実装。応答はテストで帯域作用を確認済み。
- 12AX7 段（V1-A/V1-B）: 非線形は biased-tanh による単段近似（偶数次倍音・非対称）。デバイス係数は未取得のため **INFERRED/APPROXIMATED**。
- ポットのカーブ（Treble/Bass/Volume のテーパ）: audio 系の近似。**APPROXIMATED**。
- 各段の絶対動作点・ヘッドルーム: 現状は「中央設定でほぼユニティ」の聴感・測定校正。実機 TP 電圧との照合は **未実施（Phase 9）**。
- Fat: 回路の意図（中低域を太く）に沿った低中域シェルフ近似。**APPROXIMATED**。

## C. 真空管の物理モデル用パラメータ（INFERRED / APPROXIMATED）

- 12AX7 / 12AT7 / 6V6 の μ・gm・rp 等のデバイス・パラメータは回路図に無い。
  - → 公開された真空管 SPICE/物理モデル（Koren モデル等）の係数を参照（INFERRED）。
  - → 実機の TP 電圧・ゲイン構造に合わせてバイアス点を同定（APPROXIMATED）。
- グリッド電流・ブロッキングディストーションの閾値は定性的挙動を近似（APPROXIMATED）。検証: 入出力カーブと THD スペクトルで妥当性確認。

## D. 出力トランス／スピーカー（UNVERIFIED 要素あり）

- OT の 1次インダクタンス・漏れインダクタンス・コア飽和特性: 回路図に無い（UNVERIFIED）。
  - → 22W 6V6 PP OT の一般値から初期近似（APPROXIMATED）、周波数依存損失＋飽和の交換可能モデルとして実装。
- スピーカー "Lightning Bolt"（Eminence 12"/50W/8Ω）の T/S パラメータ・インピーダンス曲線・実測 IR: 公開一次データ未入手（UNVERIFIED）。
  - → 実機 IR が入手できるまで Celestion 等特定モデルを前提にしない。
  - → キャビネット＋スピーカーの周波数特性は一般的 12" オープンバック近似（APPROXIMATED）、非線形は別モデル。
  - 検証: 実機録音 IR が得られ次第、同一マイク/位置条件で突き合わせ。
