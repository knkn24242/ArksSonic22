# 回路解析（circuit_analysis.md）

出典: 純正サービス回路図 R1（図番 0078327000 Rev A, 2010-01-08）。
定数はすべて同図から直接読み取ったもの。読み取りに確信がある値は **VERIFIED**、
図から読めるが実装前に最終転記が必要な箇所は **要精読** と付す。捏造値は無い。

座標系: 回路図は V1〜V7 の管番号、R/C 番号で統一されている。以下は信号経路順。

---

## 1. 入力段（Vintage/Burn 共用）— VERIFIED

```
INPUT J1 ──[R1 10k]──┬── grid(2) V1-A
                     └──[R2 1M]── GND     (入力ロード)
```
- V1-A（12AX7A）初段:
  - プレート負荷 **R3 100k 1/2W**（B+ へ）
  - カソード **R4 1.5k** ＋ バイパス **C1 22µF**（カソード電圧 TP15 ≈ +1.35VDC）
  - プレート出力 → 上部レールで Vintage トーンスタックへ直結
  - **C2 .0022µF/400V** がプレートノードから Burn 経路・チャンネル分岐へ結合
- R5 1M（Vintage/Burn 分岐のグリッドリーク系）

初段 V1-A は両チャンネル共用。以降 **K1（Vintage/Burn リレー）** で経路が分岐する。

---

## 2. Vintage チャンネル — VERIFIED

ブラックフェイス（'65 Deluxe Reverb）系。Middle 無し、Treble/Bass/Volume＋Fat。

### 2.1 トーンスタック（V1-A プレート直後）
古典的 Fender 受動トーンスタック:
- Treble ポット **R9 250kΩ(30A=オーディオカーブ)** ／ トレブルキャップ **C4 250pF/1kV**
- スロープ抵抗 **R8 100k**
- Bass ポット **R10 250kΩ(15A)** ／ ベースキャップ **C5 0.1µF/400V ＋ C6 0.047µF/400V**
- **R11 6.8k**（ベース→GND）
- Volume（Vintage）**R12 1MΩ(30A)**

### 2.2 Fat スイッチ（リレー K3）
- K3-A: **R13 10M**、**C7 47pF/500V** を切替投入 → 中域を持ち上げる
- K3-B（NORMAL/FAT）: **R7 1M**
- Fat ON で C7（47pF）／R13（10M）が Volume 周りの応答を変え、中低域を太らせる構成。

### 2.3 第2段 V1-B（Vintage）— VERIFIED
- グリッド直列 **R14 1.5k**
- プレート負荷 **R15 100k 1/2W**
- カソード **R16 1.5k** ＋ **C8 2.2µF**
- 出力結合 **C9 0.22µF/400V**
- グリッドリーク系 **R32 4.7M / R33 4.7M / R17 4.7M**

Vintage は V1-A → トーン → V1-B → 出力ドライバ段 V2-B（共用）→ Volume → チャンネルセレクト。

---

## 3. Burn チャンネル — VERIFIED（段構成）／一部 要精読（Burn TMB ポット）

ハイゲイン。3 ゲイン段＋3バンド（TMB）トーン。

### 3.1 Gain 1（V1-A 後）
```
V1-A plate ─[C2 .0022]─[R6 15k]─ GAIN1 ポット R31 250k(15A) ─ ... ─ grid V1-B
                                  └─[C15 470pF/500V]─ GND
```
- GAIN1 **R31 250kΩ(15A)**、**R6 15k**、**C15 470pF/500V**
- V1-B を Burn の第2ゲイン段として使用（定数は 2.3 と共通の管、動作点は Burn 経路で異なる）

### 3.2 Gain 2（V1-B 後 → V2-A）
```
V1-B plate ─[C9 .22]─[K6-B]─┬[R33/R17 4.7M grid leak]
                            └[C16 .22/400V]─[C18 47pF/500V]─ GAIN2 R35 250k(15A)
                                 ─[R37 110k]─[R39 1.5k]─ grid(2) V2-A
```
- GAIN2 **R35 250kΩ(15A)**、**R37 110k**、**R39 1.5k**
- 分圧/対GND **R36 20k**、**R38 10k**

### 3.3 第3ゲイン段 V2-A — VERIFIED
- プレート負荷 **R40 100k 1/2W**（TP19 ≈ 1.60VAC）
- カソード **R34 1.5k** ＋ **C17 22µF/25V**（TP20 ≈ +1.58VDC）
- 出力 **C20 0.047µF/400V** → **R42 470k** → K7-A（Burn）→ V2-B

### 3.4 Burn トーンスタック（TMB）— VERIFIED（R1 から精密転記済み）
Fender 型 TMB。回路図の実定数:
- Treble ポット **R47 250kB（リニア）** ／ トレブルキャップ **C22 150pF/1kV**
- Bass ポット **R48 250k15A（オーディオ）** ／ ベースキャップ **C23 0.15µF/400V、C24 0.022µF/400V**
- Mid ポット **R49 25kB（リニア）**
- スロープ抵抗 **R46 120k**、出力直列 **R50 220k**
- グリッドリーク R109 1M / R122 1M
- Burn Volume **R51 250kΩ(30A)**、R28 100k、R29 15k、R30 1M（出力段グリッドリーク）

（この定数を Fender 伝達関数に写像: R1=250k/R2=250k/R3=25k/R4=120k, C1=150pF/C2=0.15µF/C3=0.022µF、Mid は可変）

### 3.5 出力ドライバ段 V2-B（両ch 共用）— VERIFIED
- プレート負荷 **R26 100k 1/2W**（→ WJ15/P24, パワーアンプ段へ）
- カソード **R27 1.5k** ＋ **C13 2.2µF**（TP22 ≈ +1.50VDC）
- グリッドリーク **R25 470k**、周辺 R109 1M / R43 100k / R44 100k
- 出力結合 **C14 0.22µF/400V**

### 3.6 チャンネルセレクト（出力ミックス）
- リレー **K2-B**: 11=NC(Vintage) / 9=NO(Burn) / 13=共通 → FX ループ／位相反転段へ
- Vintage Volume（R12 1M）と Burn Volume（R51 250k）が各経路を担い、K2 で選択

---

## 4. スプリング・リバーブ（Sheet 1）— VERIFIED（構成）

- ドライバ: **V3（12AT7）** ＋ オペアンプ（4560 系、±15V 駆動）
- タンク: **4AB3C1B**（P/N 0084083000、4スプリング・ロングディケイ）
- リカバリ: **V4（12AX7A）** でタンク出力を回収・増幅
- Dry/Wet ミックス後、Reverb ポット（共有、R1 の REVERB）で量を調整。1 ノブ共有・チャンネル割当不可。

---

## 5. FX ループ（Sheet 1）— VERIFIED（構成）

- バッファード・ループ。オペアンプ **TL072（U3/U4）** で Send/Return を構成。
- 直列（挿入）動作、フットスイッチで ON/OFF。SEND/RETURN 端子は背面。

---

## 6. 位相反転段 V5（12AT7）— VERIFIED

- ロングテールド・ペア（差動）位相反転。
- 入力結合 **C68 0.01µF/400V**（PAMP_IN から）
- 周辺: R127（グリッド基準/HV）、**R128 22k**、R129/R130、**R131 1M**、尾部 **R132 820Ω**、R133 47、**R134 3.3k 5W**
- 6V6 グリッドへ直列ストッパ **R138 / R139 1.5k**（TP44 ≈ +70.3VDC）

---

## 7. パワー段 6V6 プッシュプル（Sheet 2）— VERIFIED

- 出力管 **V6 / V7 6V6GT**、プッシュプル、固定バイアス
- グリッドリーク **R140 / R141 1k**、スクリーン直列 **R142 / R143 470Ω/1W**
- プレート間/プレート–GND 保護ダイオード **D37 / D38**
- 出力トランス **OT P/N 0041318000**: 1次=B+センタータップ、2次 8Ω → スピーカー端子 J8(EXT)/J9(MAIN)
- **ネガティブフィードバック: R132 820Ω** を OT 2次（WJ22）から位相反転段へ（Deluxe Reverb 系の NFB と一致）

---

## 8. 電源（Sheet 2）— VERIFIED

- 電源トランス（国内）P/N 0078334000、整流 **ソリッドステート・ブリッジ D39–D42（1N4006）**
- B+ フィルタ/分圧: **R148 4.7k/2W、R150 1k/2W、R151 1k/2W**、**C78 47µF/500V、C80 22µF/500V、C82–C84 22µF/450V**、チョーク **L1**
- B+ タップ: **+420V / +418V / +376V / +317V / +280V**
- スタンバイ **S2**
- 固定バイアス供給: **−43.7V / −54.5V**、バイアス調整 **R156（BIAS ADJ）**、**R157 82k**、D43–D48（1N4006）
- SS/リレー/FX/リバーブ用 **±15V レギュレータ（7815 / 7915）**

---

## 9. 信号経路サマリ（実装のブロック分割）

```
IN ─ 入力ロード(R1/R2) ─ V1-A(初段) ─┬─[Vintage] トーン(TMBない:TB) ─ Fat ─ V1-B ─┐
                                      │                                             ├─ V2-B(共用ドライバ) ─ Volume ─ K2 ─┐
                                      └─[Burn] Gain1 ─ V1-B ─ Gain2 ─ V2-A ─ TMBトーン ─┘                                   │
                                                                                                                            │
   リバーブ(V3ドライブ→4AB3C1B→V4回収) ──(Dry/Wet)──────────────────────────────────────────────────────────────────────┤
                                                                                                                            │
   FXループ(TL072 send/return) ─ V5 位相反転(LTP) ─ 6V6×2 PP ─ OT(0041318000) ─ NFB(R132 820Ω) ─ SP(12"8Ω) ─ OUT
```

各ブロックは独立クラス（交換可能）として実装する（[../README 予定] 参照）。
